# Tool 图标按工具名映射

## 目标

将 `ToolBlockRender` 中当前固定的 `icon={<ToolOutlined />}`，改为“按工具名渲染对应 icon”，覆盖你列出的工具（`Context7`、`天气查询`、`联网搜索`、`代码执行`）。

现状参考：

- [ToolBlockRender/index.tsx](/Users/apple/Desktop/code/chat-agent/frontend/src/pages/ChatPage/components/ChatMessage/AssistantMessage/ContentBlocksRender/ToolBlockRender/index.tsx)
- [vite.config.ts](/Users/apple/Desktop/code/chat-agent/frontend/vite.config.ts)（已启用 `vite-plugin-svgr`，支持 `?react`）

## 推荐实现（方案 A：SVG React 组件映射）

1. 新增工具图标资源（建议放在 `frontend/src/assets/svg/mcp-tools/`），例如：
  - `context7.svg`
  - `weather.svg`
  - `web-search.svg`
  - `code-exec.svg`
2. 在 `ToolBlockRender` 同目录新增一个映射模块（如 `toolIcons.tsx`）：
  - import 各 SVG：`import Context7Icon from "@/assets/svg/mcp-tools/context7.svg?react"`
  - 建立 `toolName -> ReactNode` 映射，优先用 tool 原始名（`toolUseBlock.name`）匹配：
    - `web_search` -> 联网搜索 icon
    - `search_city|get_current_weather|get_weather_hourly_forecast|get_weather_daily_forecast` -> 天气 icon
    - `execute_code` -> 代码执行 icon
    - `resolve-library-id|get-library-docs`（或后端最终返回的 Context7 工具名）-> Context7 icon
  - 提供默认回退：`ToolOutlined`
3. 在 `ToolBlockRender` 中替换 icon 逻辑：
  - 从固定 `icon={<ToolOutlined />}` 改为 `icon={getToolIcon(toolUseBlock.name)}`

## 备选实现（方案 B：PNG 资源 URL 映射）

1. 图标使用 `png` 放在 `frontend/src/assets/images/mcp-tools/`。
2. 使用 `import weatherPng from ".../weather.png"` + `<img src={...} />` 返回图标。
3. 控制样式统一（`w-4 h-4 object-contain`），并保留默认 `ToolOutlined` 回退。

## 混合实现（方案 C：优先 SVG，缺失时回退 PNG）

- 对清晰度要求高的图标优先 SVG；若第三方只提供位图则使用 PNG。
- 在映射层对每个工具声明 `type: "svg" | "png"`，统一通过 `getToolIcon` 返回 ReactNode。

## 关键设计点

- 以 **tool 函数名**（如 `web_search`）作为主键，而非展示名，避免中英文文案变化导致映射失效。
- 映射做“分组匹配”（天气一组、搜索一组），避免每个工具重复写样式。
- 保留未知工具回退图标，避免线上出现空 icon。

## 验收标准

- 4 类工具展示对应 icon；未知工具显示默认图标。
- 折叠/展开、流式状态（`blink`）不受影响。
- 图标在深浅色主题下可辨识（建议 SVG 用 `currentColor` 或带透明底）。
