# 移除前端工具选择并改为后端控制

## 目标
- 移除聊天输入区的工具选择交互（`ToolsSetting` 及其表单字段）。
- 前端不再维护/提交 `mcpAutoMode`、`sourceConfig` 两个字段。
- 保留 `websiteBuildMode` 与现有提示词联动能力。

## 变更方案
- 在 [`frontend/src/pages/ChatPage/components/ChatInput/components/ChatInputFooter.tsx`](frontend/src/pages/ChatPage/components/ChatInput/components/ChatInputFooter.tsx) 中：
  - 删除 `ToolsSetting` 引用与渲染。
  - 删除隐藏表单项 `mcpAutoMode`、`sourceConfig`。
- 在 [`frontend/src/pages/ChatPage/components/ChatInput/hooks.ts`](frontend/src/pages/ChatPage/components/ChatInput/hooks.ts) 中：
  - 精简 `defaultFormValue`（去掉 `mcpAutoMode`、`sourceConfig`）。
  - 删除基于 MCP 配置构造 `sourceConfig` 的逻辑和 `websiteBuildMode` 对 `mcpAutoMode/sourceConfig` 的联动逻辑。
  - 保留模型默认值与 `websiteBuildMode` 的本地持久化能力。
- 在 [`frontend/src/pages/ChatPage/components/ChatInput/constant.ts`](frontend/src/pages/ChatPage/components/ChatInput/constant.ts) 中：
  - 删除 `websiteBuildModeForcedOffMcpIds` 常量。
  - 删除 `names.mcpAutoMode`、`names.sourceConfig`。
- 在 [`frontend/src/interfaces/chat.ts`](frontend/src/interfaces/chat.ts) 中：
  - 从 `ChatInputConfig` / `ChatRequest` 中移除 `mcpAutoMode`、`sourceConfig` 类型字段。
  - 同步影响 `ChatInputFormValues` 与 `messageMetadata` 的类型收敛。
- 在 [`frontend/src/services/chat.ts`](frontend/src/services/chat.ts) 中：
  - 删除 `snakecaseKeys` 的 `exclude: Object.keys(data.sourceConfig || {})` 特殊处理，改为普通深度 snake_case 转换。

## 兼容性与验证
- 后端 `ChatRequest` 对 `mcp_auto_mode`、`source_config` 有默认值（`True` 与空配置），前端不传时可由后端默认策略接管。
- 运行前端检查：
  - `cd frontend && vp lint .`
  - `cd frontend && vp build`
- 手动验证：
  - 聊天输入区不再出现工具选择入口。
  - 发送消息正常，SSE 流正常。
  - `websiteBuildMode` 开关仍可切换，欢迎页提示词卡片联动不受影响。
