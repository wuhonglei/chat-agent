# Chat-Agent Agent 模式技能调试清单

这 13 个技能可以从功能维度分为以下几类：

---

## 📊 **数据与分析类**
| 技能 | 核心能力 |
|------|----------|
| **data-analysis** | 处理 Excel/CSV，统计分析、透视表、SQL 查询 |
| **chart-visualization** | 26 种图表类型，智能可视化数据 |
| **consulting-analysis** | 专业研究报告：市场/消费者/竞品/财务分析 |
| **deep-research** | 多角度网络深度调研，系统性信息收集 |

---

## 📝 **内容创作类**
| 技能 | 核心能力 |
|------|----------|
| **newsletter-generation** | 新闻简报、周刊摘要、行业速览 |
| **ppt-generation** | 自动生成视觉丰富的 PPT 演示文稿 |
| **image-generation** | AI 图像生成，人物/场景/产品视觉创作 |
| **aihot** | 中文 AI 日报/资讯简报 |

---

## 💻 **开发与部署类**
| 技能 | 核心能力 |
|------|----------|
| **webapp-building** | React + TypeScript + Tailwind + shadcn/ui 构建 Web 应用 |
| **vercel-deploy** | 一键部署应用到 Vercel 生产/预览环境 |

---

## 🔧 **系统与工具类**
| 技能 | 核心能力 |
|------|----------|
| **find-skills** | 发现、搜索并安装新技能 |
| **skill-creator** | 创建、修改、优化、评估自定义技能 |
| **surprise-me** | 动态组合多个技能，创造意外惊喜体验 |

---

### 📌 一句话总结
> **数据分析（4 个）→ 内容创作（4 个）→ 开发部署（2 个）→ 系统工具（3 个）**，覆盖了从信息获取、分析加工、内容产出到应用构建的完整链路。
