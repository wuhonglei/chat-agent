GEO Playwright 采集流程

从 Kafka 消费消息开始，至结果上传 GeoServer 结束

1 Kafka 消息到达 & 解析 KafkaConsumerService.ts
  • 应用启动时 app.ts 调用 kafkaConsumerService.startConsumer()
  • Consumer 订阅 Topic，eachBatch 回调逐条解析 JSON → TaskMessage
  • 校验 validateTask() 检查 id / prompt / taskStatus / aiPlatform 合法性
  • 解析或校验失败 → 直接提交 offset 跳过，避免死循环
2 并发控制 & 账号池检查 KafkaConsumerService.ts
  • 并发 MAX_CONCURRENT_TASKS = 1，超限则 pauseConsumption('concurrency')
  • 账号池 redisServer.getFreeAccountCount() 检查可用账号数
  • 账号不足 → pauseConsumption('emptyPool')，每 5 秒轮询等待恢复
  • 两种暂停原因独立管理，全部清除后才恢复消费
3 预占用账号 & 提交 Offset KafkaConsumerService.ts
  • acquireSamplingAccount(task) 从 Redis 原子获取账号（含 storageState / proxyPort）
  • 预占用成功后才 resolveOffset + commitOffsets，保证 offset 不会先于取号提交
  • 取号失败 → 移除任务、暂停消费、等待账号池恢复
  • Fire-and-forget 提交后台执行，不阻塞下一条消息
4 通知 GeoServer → Processing KafkaConsumerService.ts → GeoServerService.ts
  • geoServerService.processingTask(taskId) 更新任务状态为 Processing
  • 失败仅记录日志，不中断主流程
5 Executor 执行（含重试） executor.ts
  • Executor.execute(task, { prefetchedAccount })
  • 默认 3 次重试，每次 5 分钟超时
  • 第 2 次起随机切换代理端口
  • 提前终止 AccountLoginExpiredError / NoWebSearchError

单次尝试流程（runOneAttempt）

initialize → setAcquiredAccount → createBrowserContext → initializePage → performAIInteraction → collectData → markSuccess → cleanup

超时保护

Promise.race 包裹整个尝试，超时抛出 任务执行超时，触发重试或放弃

5a 创建浏览器上下文 contextManager.ts
  • contextManager.createContext({ storageState, proxyPort, region, headless })
  • 注入账号 Cookie（storageState）、代理、区域配置
  • Playwright 浏览器实例由 BrowserManager 管理，Context 隔离
5b 打开平台页面 & 登录检查 createSamplingPlatformPage.ts / ChatGPTPage.ts / GoogleAIOverviewPage.ts
  • createSamplingPlatformPage(aiPlatform, page) 按平台创建页面对象
  • platformPage.open() 导航到目标平台
  • 登录失效 → Redis 标记过期 + SeaTalk 告警 + 抛 AccountLoginExpiredError 终止重试
5c AI 交互 & 数据采集 ChatGPTPage.ts / GoogleAIOverviewPage.ts
  • performInteraction(prompt) — 输入 prompt，等待 AI 完成回复
  • collectData() — 提取 markdownContent / rawData / productData / citedSources
  • 无引用 citationCount = 0 → 抛 NoWebSearchError 终止重试
6 Cleanup — 截图上传 & 资源回收 executor.ts
  • platformPage.uploadImage(ossService) — 截图上传 OSS，URL 写入结果
  • 成功时回写 storageState 到 Redis（Cookie 刷新）
  • contextManager.closeContext() — 关闭浏览器上下文
  • 记录耗时、截图哈希、数据摘要等日志
7 上传结果到 GeoServer KafkaConsumerService.ts → GeoServerService.ts
  • geoServerService.uploadTaskResult(result)
  • 上传内容：TaskReportRequest（含 markdownContent / rawData / productData / citedSources / screenshotUrl / metadata / duration）
  • 失败仅记录日志，不影响后续流程
8 释放账号 & 恢复消费 KafkaConsumerService.ts
  • finally 块中 releaseSamplingAccount(accountKey) — 无论成败都释放账号回池
  • taskManager.removeRunningTask() — 移除运行中任务计数
  • checkAndResumeConsuming() — 并发数恢复后移除 concurrency 暂停原因，尝试恢复消费
