剪辑 Agent 完整链路（面试版·架构推演）

用户上传素材 → 多模态理解 → 意图解析 → Plan-and-Execute 步骤规划 → 工具编排（剪辑/特效/字幕/音频）→ 质量评估 → 输出成品
基于 Agent 架构通用模式 + 视频创作领域特点推演，非特定产品内部实现

素材预处理

  • FFmpeg scene detect 关键帧提取
  • Demucs 音频三轨分离
  • Whisper ASR 带时间戳字幕
  • VLM 多模态场景打标

意图理解

  • VLM 理解视觉内容
  • LLM 解析用户编辑意图
  • 结构化输出: style/target/mood
  • 少样本 Prompt + 输出校验

Plan-and-Execute

  • Planner 生成 DAG 编辑步骤
  • 拓扑排序: 无依赖步骤并行
  • Re-Planner 自愈: 失败后重排
  • 用户微调: 局部 Re-Plan

工具编排

  • FFmpeg 剪辑/转场/编码
  • 字幕引擎: SRT/ASS 烧录
  • 特效: LUT/滤镜/动态贴纸
  • 超分 Real-ESRGAN / 插帧 RIFE

质量保障

  • CLIP 视觉连贯性检测
  • 音画同步校验
  • VLM 审美评分 Gate
  • max_replan=2 防无限循环
