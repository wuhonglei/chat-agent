Chat Agent 完整链路架构（面试版）

用户消息 → 上下文组装 → LLM 调用 → 工具执行 → 流式输出  |  每环节标注技术选型

流式架构

  • SSE (Server-Sent Events) 全链路流式
  • Redis Stream 多 Worker 缓冲 + 断线恢复
  • EventSource 前端逐字渲染
  • Langfuse propagate_attributes 全链路追踪

上下文管理

  • 滑动窗口 + 自动摘要压缩历史
  • pgvector 余弦距离 Top-K 纯向量检索
  • Mem0 用户长期记忆
  • tiktoken TokenCalculator 控制窗口

Agent 循环

  • 单 Agent 多轮工具调用 (max_rounds)
  • MCP 协议统一工具接入
  • tool_call → tool_result 消息回注
  • Title Generation 异步并行

工程保障

  • JWT RSA 鉴权 + 幂等去重
  • Redis SET NX 防重复提交
  • Langfuse Trace/Span 可观测
  • Graceful Stop (Redis 轮询取消)
