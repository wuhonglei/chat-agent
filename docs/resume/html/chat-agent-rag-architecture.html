Chat Agent — 附件 RAG 架构

上传写入路径 + 查询检索路径 · 面试版

短文档策略（≤ 10K tokens）

  • • 直接全文注入 system prompt，不做分块
  • • 覆盖 95%+ 的常见附件（合同、简历、短报告）
  • • 零向量化开销，响应最快
  • • 代码路径：KbContextBlock.content 直接拼接

长文档策略（> 10K tokens）

  • • MarkdownTextSplitter 分块（1000 字/块，200 字重叠）
  • • bge-m3 (DashScope) 向量化，1024 维
  • • pgvector 余弦相似度检索，top_k=6
  • • 惰性索引：首次查询时才做分块+向量化，后续复用
  • • 检索结果按 chunk_idx 排序合并，保持原文顺序

存储与索引设计

  • • content_id = SHA-256(文件内容)，天然去重
  • • 磁盘：uploads/{conv_id}/ 原文件 + derived/ Markdown
  • • 向量表：kb_file_chunk_embeddings (pgvector)
  • • 索引键：(user_id, content_id) → 按用户隔离
  • • 会话级隔离，删除会话时 CASCADE 清理
