Chat Agent 后端架构

面试版 — 全栈 AI 对话平台后端技术架构总览

🛠 技术栈
框架FastAPI + Uvicorn / Gunicorn
语言Python 3.10+
数据库PostgreSQL + pgvector + SQLModel ORM + Alembic 迁移
缓存Redis — SSE Stream Relay + Turn 幂等去重（SET NX）
LLMDeepSeek / OpenAI 兼容 API（多 Provider + 场景化解析）
工具协议MCP (Model Context Protocol) — fastmcp
可观测Langfuse（trace / generation / 工具调用全链路追踪）
配置中心Nacos（支持热更新，不可达时降级到 env / 空配置）
对象存储腾讯云 COS

  • tool_call_policy.py — 工具调用策略（控制调用轮次 / 终止条件）
服务层 app/services/ — 按领域分包
  • chat/ — 对话核心（编排器、流式中继、RAG 上下文、幂等存储）
  • conversation/ — 会话 DB 操作 + 上下文摘要
  • message/ — 消息持久化
  • user/ — 用户管理 + Mem0 记忆服务
  • auth/ — 短信验证、验证码存储

  • base_service/ — 模型解析器（provider/model → LLMConfig）

  • cache.py — 工具结果缓存
  • tavily_mcp — 联网搜索
  • weather_mcp — 天气查询
  • code_exec_mcp — 代码执行沙箱（Piston，stdlib only）
  • time_mcp — 时间服务

基础设施层 app/core/
  • config.py — Pydantic Settings 分层配置
  • db.py — PostgreSQL 连接池（pool_size=5）
  • redis.py — Redis 连接池
  • jwt.py — JWT RSA 密钥管理

VFS 层 app/vfs/ — 虚拟文件系统

  • uploads_provider.py — 上传文件提供
⚡ 核心请求流程（SSE 流式对话）
  1. Client → POST /api/chat/stream 前端发起流式对话请求，携带 JWT Token
  2. JWT 认证 → Turn 幂等检查 Redis SET NX 防止重复提交同一轮对话
  3. chat_session_agent 编排 入口 Agent，协调以下子步骤：
  4. history_context_service + context_compactor 加载历史消息，压缩过长上下文以适配 LLM context window
  5. kb_rag_context_service pgvector 向量相似度检索，注入相关知识片段
  6. MCP Tools Agent 调用外部工具（搜索 / 天气 / 代码执行），支持多轮工具调用
  7. Response Agent → 流式生成回复 SSE delta 事件逐 token 推送到前端
  8. stream_relay + Redis Pub/Sub 通过 Redis 解耦 Agent 生成和客户端消费，支持断线重连
  9. Langfuse 记录 trace / generation / tool span 全链路可观测，支持延迟分析和质量监控
  10. Title Agent（异步） 异步生成会话标题，不阻塞主响应流程
💡 关键设计亮点（面试展开点）

1. MCP 工具架构

标准化工具协议，支持本地 / HTTP / Stdio 三种传输方式。Nacos 热更新 MCP 配置，工具结果缓存减少重复调用。

2. RAG 检索优化

pgvector 向量检索 + 惰性索引（上传时不索引，检索时按需 embedding）。MarkdownTextSplitter + bge-m3，317 条测试集系统性调优。

3. SSE 流式 + Redis 中继

stream_relay 通过 Redis Pub/Sub 解耦 Agent 生成和客户端消费，支持断线重连，保证消息不丢失。

4. Turn 幂等

Redis SET NX 防止重复提交同一轮对话，避免重复 LLM 调用和消息写入。

5. 分层配置

Nacos → env var → 默认值，Nacos 不可达时优雅降级。支持 Nacos 热更新 MCP 和模型配置。

6. Langfuse 全链路可观测

每次 LLM 调用 / 工具调用都有 trace / span，支持延迟分析、token 消耗统计和质量监控。

7. VFS 虚拟文件系统

统一路径映射，Agent 通过虚拟路径访问用户数据，隔离不同会话的 workspace / uploads / outputs。
