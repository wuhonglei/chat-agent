⚡ 核心请求流程（SSE 流式对话）
  1. Client → POST /api/chat/stream 前端发起流式对话请求，携带 JWT Token
  2. JWT 认证 → Turn 幂等检查 Redis SET NX 防止重复提交同一轮对话
  3. chat_session_agent 编排 入口 Agent，协调以下子步骤：
  4. history_context_service + context_compactor 加载历史消息，压缩过长上下文以适配 LLM context window
  5. kb_rag_context_service pgvector 向量相似度检索，注入相关知识片段
  6. MCP Tools Agent 调用外部工具（搜索 / 天气 / 代码执行），支持多轮工具调用
  7. Response Agent → 流式生成回复 SSE delta 事件逐 token 推送到前端
  8. stream_relay + Redis Pub/Sub 通过 Redis 解耦 Agent 生成和客户端消费，支持断线重连
  9. Langfuse 记录 trace / generation / tool span 全链路可观测，支持延迟分析和质量监控
  10. Title Agent（异步） 异步生成会话标题，不阻塞主响应流程
💡 关键设计亮点（面试展开点）

1. MCP 工具架构

标准化工具协议，支持本地 / HTTP / Stdio 三种传输方式。Nacos 热更新 MCP 配置，工具结果缓存减少重复调用。

2. RAG 检索优化

pgvector 向量检索 + 惰性索引（上传时不索引，检索时按需 embedding）。MarkdownTextSplitter + bge-m3，317 条测试集系统性调优。

3. SSE 流式 + Redis 中继

stream_relay 通过 Redis Pub/Sub 解耦 Agent 生成和客户端消费，支持断线重连，保证消息不丢失。

4. Turn 幂等

Redis SET NX 防止重复提交同一轮对话，避免重复 LLM 调用和消息写入。

5. 分层配置

Nacos → env var → 默认值，Nacos 不可达时优雅降级。支持 Nacos 热更新 MCP 和模型配置。

6. Langfuse 全链路可观测

每次 LLM 调用 / 工具调用都有 trace / span，支持延迟分析、token 消耗统计和质量监控。

7. VFS 虚拟文件系统

统一路径映射，Agent 通过虚拟路径访问用户数据，隔离不同会话的 workspace / uploads / outputs。

⚡ 前端核心数据流
  1. 用户输入 → ChatInput 组件 文本输入 + @提及附件 + 文件上传，通过 ChatInputSender 发送
  2. chatSlice.dispatch → 消息入 Redux Store 乐观更新：立即将用户消息添加到 messages 数组
  3. services/chat.ts → SSE 流式请求 fetch-event-source 连接 POST /api/chat/stream，JWT 认证
  4. SSE 事件 → chatSlice 增量更新 contentBlocks 逐 token / 逐 block 增量拼接，维护 isStreaming 状态
  5. ContentBlocksRender → 动态渲染 按 block 类型（text/tool_call/code/image）分发到对应渲染器
  6. ToolBlockRender → registry 匹配 按 MCP server 名查找注册表，渲染工具调用参数和结果（含 diff 对比）
  7. BlockPreviewPanel → 文件预览 Excel/PPT/Word/项目文件树/文本文件 预览面板
  8. dbMiddleware → IndexedDB 持久化 Redux 状态变更自动同步到 Dexie IndexedDB，支持离线恢复
  9. StreamResumeContext → 断线重连 SSE 断线后通过 StreamResumePhase 恢复流式状态，保证消息不丢失
💡 前端关键设计亮点（面试展开点）

1. Content Block 模型

消息内容不是纯文本，而是 contentBlocks[] 数组（text / tool_call / code / image），每种 block 有独立渲染器，支持混合内容和流式增量更新。

2. Tool 渲染注册表

按 MCP server 名注册渲染器（shell / file / code / tavily 等），支持文件差异对比（FileDiffView）、代码高亮、搜索结果卡片等专用渲染。

3. SSE 流式 + 断线恢复

fetch-event-source 实现 SSE 流式接收，StreamResumeContext 维护断线恢复状态，支持 reconnect 后继续消费未完成的流。

4. 双层持久化

Redux store 通过 dbMiddleware 自动同步到 IndexedDB (Dexie)，会话消息离线可用。API 层自动做 snake_case ↔ camelCase 转换，对接 Python 后端零摩擦。

5. 文件预览面板

统一 BlockPreviewPanel 支持 Excel (xlsx)、PPT (pptx)、Word (docx)、PDF、项目文件树、文本文件预览，Agent 输出的文件可直接在前端查看。

6. 构建优化

Rolldown codeSplitting 拆分 vendor(react) / utils(axios,lodash) / ui(simplebar) / components(antd) 等 chunk，减小首屏加载体积。

7. API 拦截器链

请求拦截：自动 JWT 注入 + snake_case 转换。响应拦截：camelCase 转换 + code!=0 统一错误处理 + 401 自动跳转登录 + 会话不存在自动跳转。
