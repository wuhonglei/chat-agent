Camoufox 指纹伪装方案全景

Camoufox 是 Firefox 的反检测分支，所有指纹伪装均在 C++ / Juggler 内核层实现，通过 CAMOU_CONFIG 环境变量注入 JSON 配置，JavaScript 侧完全无痕。 共 34 个 patch，覆盖浏览器 API、渲染引擎、网络栈、媒体子系统。

架构总览

CAMOU_CONFIG (JSON) → MaskConfig.hpp (解析层) → patches/*.patch (注入点) → Firefox C++ API 返回伪装值

MaskConfig.hpp 统一从 CAMOU_CONFIG 环境变量读取 JSON，提供 GetString / GetUint32 / GetDouble / GetBool / GetStringList 等类型安全接口。 各 patch 在 Firefox 的 DOM、Media、Net、GFX 模块中插入读取逻辑，替换真实指纹后返回给 JS 层。
分块机制：长 JSON 拆为 CAMOU_CONFIG_1, _2, ... (Linux 每块 32KB，Windows 2KB)，C++ 端按序拼接后解析。

浏览器身份伪装

Navigator 属性 navigator-spoofing.patch
  • navigator.userAgent / platform / oscpu
  • navigator.hardwareConcurrency (CPU 核心数)
  • 每个 BrowsingContext 独立配置，支持多标签不同身份
HTTP 请求头 network-patches.patch
  • User-Agent / Accept / Accept-Language 同步伪装
  • 修改 nsHttpHandler 层，与 navigator 值一致
语言 / Locale locale-spoofing.patch
  • navigator.language / languages
  • Accept-Language HTTP 头
  • 支持 locale:language + locale:region 分别设置
时区 timezone-spoofing.patch
  • Date / Intl.DateTimeFormat 返回伪装时区
  • 修改 TimezoneManager，Worker 进程也可读取
  • Fallback 到 CAMOU_CONFIG 的 timezone 字段
地理位置 geolocation-spoofing.patch
  • 伪造 GeolocationPosition 的经纬度
  • 修改 dom/geolocation/Geolocation.cpp
  • 配置项：geolocation:latitude / geolocation:longitude

与其他方案对比

维度 Camoufox (C++ Patch) puppeteer-extra-stealth (JS 注入) Firefox RFP (about:config)
伪装层级 C++ / DOM 内核 JS 页面层 override C++ 内核
页面侧可检测性 不可检测（无 override 痕迹） 可通过 toString() 检测 不可检测
WebGL 伪装 全量（vendor/renderer/params/shader） 不支持 仅报告通用值
音频指纹 采样率 + 确定性噪声注入 不支持 仅禁用 AudioContext

WebRTC IP Per-context 伪造 IPv4/IPv6 不支持 禁用 mDNS
多身份隔离 Per-BrowsingContext 独立配置 全局生效 全局生效
配置注入方式 CAMOU_CONFIG 环境变量（JSON） JS 脚本注入 about:config pref

配置注入机制

环境变量分块：Python 库将 JSON 按 32KB (Linux) / 2KB (Windows) 拆分为 CAMOU_CONFIG_1, CAMOU_CONFIG_2, ...，C++ 端按序拼接后解析。若无分块变量，fallback 读单一 CAMOU_CONFIG。

直接启动：支持在 shell 中 CAMOU_CONFIG='{...}' ./camoufox-bin 直接传值。

Python 库：通过 Playwright 的 env 参数传递，会替换整个进程环境，shell 环境变量被覆盖。

配置文件：camoufox.cfg 随构建打包，启动时自动加载。
