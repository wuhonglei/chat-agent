## ⚠️ 注意事项

1. **API 限流**: Langfuse API 有请求频率限制，批量导入时需要控制速度
2. **数据备份**: 导入前建议备份原始数据文件
3. **错误处理**: 导入过程中遇到错误会记录日志，不会中断整个流程
4. **数据一致性**: 使用确定性 Trace ID，确保数据可追溯
