# 认证流程（当前实现）

本文档描述当前仓库中的认证实现：短信验证码登录、微信登录、JWT 鉴权。

## 1. 关键接口

认证接口统一挂在 `/api/auth`：

- `POST /api/auth/sms/send`：发送短信验证码
- `POST /api/auth/sms/login`：短信验证码登录
- `POST /api/auth/wechat/init`：微信登录初始化
- `POST /api/auth/wechat/login`：微信登录回调处理
- `POST /api/auth/logout`：退出登录

## 2. 前端认证流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant FE as 前端
    participant BE as 后端
    participant LS as localStorage

    Note over FE,LS: 页面初始化
    FE->>LS: 读取 x-secret-token-info
    LS-->>FE: token 或 null

    alt 未登录
        FE->>User: 跳转/展示 /login
    else 已登录
        FE->>User: 进入 /chat
    end

    Note over User,BE: 短信登录
    User->>FE: 输入手机号/验证码
    FE->>BE: POST /api/auth/sms/login
    BE-->>FE: ApiResponse + 响应头 x-secret-token-info
    FE->>LS: 保存 token
    FE->>User: 跳转 /chat
```

## 3. 后端认证流程

```mermaid
sequenceDiagram
    participant FE as 前端
    participant API as FastAPI
    participant SMS as 短信服务
    participant JWT as JWTManager
    participant MW as 认证依赖(require_auth/get_auth_token_info)

    FE->>API: POST /api/auth/sms/send
    API->>SMS: 发送验证码
    SMS-->>API: 发送结果
    API-->>FE: ApiResponse

    FE->>API: POST /api/auth/sms/login
    API->>SMS: 验证验证码
    API->>JWT: 生成服务端 JWT
    API-->>FE: 响应头 x-secret-token-info

    FE->>API: 访问受保护接口（如 /api/conversation/list）
    API->>MW: 校验 Authorization: Bearer <token>
    MW-->>API: 认证通过/失败
    API-->>FE: 业务响应或 401
```

## 4. 请求鉴权约定

- 前端请求受保护接口时，需携带：
  - `Authorization: Bearer <x-secret-token-info>`
- 后端通过依赖注入完成认证：
  - `require_auth`：仅校验通过与否
  - `get_auth_token_info`：校验并提取用户信息（如 `user_id`）
- 当返回 `401` 时，前端应清理本地 token 并跳转登录页。

## 5. 与旧文档的差异说明

- 当前实现中不再使用 Cloudbase 作为认证主流程描述；
- 文档中的业务接口统一采用 `/api/*` 前缀；
- 会话相关接口应使用 `/api/conversation/*`，而不是 `/conversations`。
