### 五、联网搜索

| 流程点 | 是否正确 | 改进建议 |
|--------|----------|----------|
| 什么时候进行联网搜索 | 需要明确触发条件 | 建立基于意图分类或上下文不足的判定逻辑 |
| SERP 网页 URL 是否需要再次排序 | 推荐重排序 | 使用 Cross-Encoder 或 LLM 对内容重新评估 |
| 是否需要对 SERP 网页 URL 进行爬取 | 必须爬取 | 确保爬取失败时有降级策略（如使用 snippet） |
| 爬取得到的网页内容是否需要分块 | 必须分块 | 按语义边界或 token 长度分块 |
| 分块后的网页内容如何进行去重 | 必须去重 | 使用指纹或语义相似度进行去重 |
| 返回结果中如何得到引用块来源 | 必须明确引用 | 保留块的来源元数据并在回答中标注 |
