## 本地微信扫码登录流程

> 背景: 前端微信二维码显示使用的是 Wx SDK，该 SDK 需要指明申请的 `授权回调域(在线域名)` 下的回调地址 redirect_uri，因此微信扫码登录成功后会跳转到 redirect_uri. 该 redirect_uri 携带了 code，服务器需要用该 code 获取 access_token.

为了将 `https://chat.wuhonglei.cn` 请求转发到本地 `http://localhost:3000/`，我们可以使用 whistle Rules 将请求转发至本地，whistle Rules 的配置如下:

```whistle
# 一条规则即可同时支持：HTTPS → HTTP、WSS → WS 转发到 localhost:3000
https://chat.wuhonglei.cn http://localhost:3000/
wss://chat.wuhonglei.cn ws://localhost:3000/  # 可选：单独指定 WSS 转发规则，更清晰
```
