# 微信扫码登录功能实现计划

## 概述

在现有的登录页面中添加微信扫码登录功能，使用微信官方 JS-SDK 实现二维码显示和登录状态轮询。

## 实现步骤

### 1. 添加接口类型定义

在 `src/interfaces/auth.ts` 中添加微信登录相关的接口类型：

- `WeChatLoginInitResponse`: 初始化微信登录响应（包含二维码 ticket 或 URL）
- `WeChatLoginCheckResponse`: 轮询检查登录状态响应（包含状态码、用户信息等）
- `WeChatLoginStatus`: 登录状态枚举（待扫码、已扫码、已确认、已过期等）

### 2. 添加 API 服务方法

在 `src/services/user.ts` 中添加微信登录相关的 API 方法：

- `initWeChatLogin()`: 初始化微信登录，获取二维码信息
- `checkWeChatLoginStatus(ticket: string)`: 轮询检查登录状态

### 3. 创建微信登录组件

创建 `src/pages/LoginPage/components/WeChatLoginForm.tsx`：

- 使用微信 JS-SDK
- 实现二维码显示（使用 Ant Design 的 Image 或自定义组件）
- 实现轮询机制（使用 `useRequest` 和 `useInterval`，每 2 秒检查一次）
- 处理不同登录状态（待扫码、已扫码、登录成功、已过期）
- 登录成功后跳转到聊天页面（复用 `VerifyCodeForm` 中的跳转逻辑）

### 4. 集成微信 JS-SDK

在 `index.html` 中引入微信 JS-SDK：

- 添加微信 JS-SDK 的 script 标签
- 配置微信 AppID（通过环境变量 `VITE_WECHAT_APPID` 获取）

### 5. 更新登录页面

在 `src/pages/LoginPage/index.tsx` 中：

- 在 `tabItems` 数组中添加微信登录 tab
- 导入并使用 `WeChatLoginForm` 组件

### 6. 环境变量配置

- 在 `vite-env.d.ts` 中添加 `VITE_WECHAT_APPID` 类型定义
- 确保环境变量可以正确读取

## 技术细节

### 轮询机制

- 使用 `ahooks` 的 `useRequest` pollingInterval 实现轮询
- 轮询间隔：2 秒
- 超时处理：二维码过期后停止轮询并提示用户刷新

### 状态管理

- 组件内部使用 `useState` 管理二维码 URL、登录状态等
- 登录成功后通过 `authHeader.setAuthorizationHeader()` 设置 token

### 错误处理

- 网络错误：显示错误提示
- 二维码过期：提示用户刷新二维码
- 登录失败：显示错误信息

## 文件清单

需要创建/修改的文件：

1. `src/interfaces/auth.ts` - 添加类型定义
2. `src/services/user.ts` - 添加 API 方法
3. `src/pages/LoginPage/components/WeChatLoginForm.tsx` - 新建组件
4. `src/pages/LoginPage/index.tsx` - 添加微信登录 tab
5. `index.html` - 引入微信 JS-SDK
6. `src/vite-env.d.ts` - 添加环境变量类型定义

## 注意事项

1. 微信 JS-SDK 需要后端提供签名等信息，如果后端暂未提供，可以先使用二维码图片 URL 的方式
2. 轮询需要在组件卸载时清理，避免内存泄漏
3. 二维码过期后需要提供刷新功能
4. 确保登录成功后的跳转逻辑与验证码登录一致
